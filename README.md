# Instructions To Install Web App

Method 1: From localhost

Run: 
 git clone https://github.com/Forinite/offline-notes-labs.git

 npm install

And Then:
npm run build 
npm run preview

Click the installation icon on the right of the search and installation should begin

Method 2: 
- Visit https://offline-notes-labs.vercel.app/

- If on desktop: Click the installation icon on the right of the search and installation should begin

- If on mobile: Click the menu Icon on the top right then find and click install
